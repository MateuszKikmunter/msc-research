# Repetition 1: model pairs with the same terminal-outcome category

Each pair compares Nova Lite and Haiku 4.5 on the same standalone question in repetition 1.
Of 160 question pairs, 128 have matching terminal-outcome categories: 121 are correct for both models and seven are semantic errors for both.
Seven of the 128 have different trajectory classes; all seven end correctly. The other 121 have the same class.
CTD = 7/128 = 5.47%. Equal outcome categories do not imply identical SQL or result rows.
